# 🤖 AutoWeReport (个人微信自动化工作汇报助手)

基于本地微信聊天记录自动分析、清洗、提炼每日工作任务和总结的 AI 智能化应用。通过高颜值的 Web 仪表盘和一键执行的物理提取引擎，将杂乱的聊天瀑布转化为结构化的跟进大纲。

## 🛠️ 安装与配置

### 1. 环境准备
推荐使用 Python 3.10+ 环境。请克隆本项目并进入根目录后，安装必要依赖：
```bash
pip install -r requirements.txt
```
*(注：内置的原生解密探针模块依赖于 `pycryptodome` 库，如果未安装，系统底层会在首次嗅探时尝试自动安装)*

### 2. 启动服务
全程无需修改代码本体，双击直接运行全栈自动化入口：
```bash
python start_app.py
```
> **后台逻辑**: 脚本会首先启动 FastAPI 异步后端引擎构建 REST 层，接着自动在浏览器为您打开操作仪表盘面板。

### 3. 在 Web Dashboard 面板中配置参数
在打开的左侧面板配置您的专属信息：
* **真实姓名 / 微信小名**: 用于帮助底层大模型识别你在聊天对象关系里的具体代号，防止大模型将“你交代给别人的需求”误认为是“指派给你的活”。
* **微信原始数据目录**: 点击框体右侧的 `[浏览...]` 按钮。
  > **💡 系统如何自动识别？**
  > 在弹窗中，请导航到电脑的微信主缓存路径（通常在 `C:/Users/用户名/Documents/xwechat_files`）。进去后会发现以 `wxid_` 开头的一长串乱码目录，每个目录代表登录过的一个微信帐号。**选中包含了 `db_storage` 文件夹的那个 wxid 目录即可！** 
* **API Base URL / API Key**: 支持一切兼容 OpenAI Completion 接口协议的服务商。
* **模型选择**: 填写具体的模型名称，如 `moonshotai/kimi-k2.5`。
填写完成后，点击下方 **保存配置** 即可。

## 🏃 飞轮流转：全自动分析链路

1. 左栏配置就绪后，点击中间上方的 **[ 🔄 一键解密并同步提取]**。
   *(系统底层会接管流程：寻找微信进程 -> 提取临时通讯密钥 -> 本地物理 SQLite 解密还原 -> json合并 -> 洗去冗余字段)*
2. 依据你想要复盘的周期，在下拉框选择 **分析时间范围** (1d/3d/7d)。
3. 点击 **[ 📊 一键生成报告]**。
4. 下方纯黑色的日志终端将实时（SSE Stream）展示 Python 后端的清洗思考链路。片刻后，右侧的流计算窗口即会渲染出排版精良的 Markdown 工作跟进总结！

*提示：每一份终态分析报告还会作为存底被静默写入本地的 `workspace/reports/` 目录中。*

## 📄 隐私条款与离线安全声明
本项目为极客向的全自动流程编排套件。为了贯彻最极端的隐私保密原则：
1. **源码防御**: 我们在自带的 `.gitignore` 中默认排除了你的生成日志、微信缓存数据库与 API 环境变量，确保您即使 `git push` 给他人使用，也绝不会包含个人聊天内容。
2. **脱离公有云方案**: 极度建议你结合 Ollama 等离线推理引擎，将 API 端点指向 `http://localhost:11434/v1`。此时，整套 `AutoWeReport` 生态系统将变成 100% 断网隔离的军工级助手。
